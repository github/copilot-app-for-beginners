# Chapter Slides

Presentation decks for each chapter of the GitHub Copilot app for Beginners course. Use them to teach a chapter or to give a visual walkthrough of it.

| Chapter | Deck |
|---|---|
| 00 | [Set Up the GitHub Copilot app](00-setup.pptx) |
| 01 | [Tour the App](01-tour-the-app.pptx) |
| 02 | [Sessions, Worktrees, and Context](02-sessions-worktrees-context.pptx) |
| 03 | [Development and GitHub Workflows](03-development-workflows.pptx) |
| 04 | [Skills and Custom Agents](04-skills-custom-agents.pptx) |
| 05 | [MCP Servers and Plugins](05-mcp-plugins.pptx) |
| 06 | [Canvases](06-canvases.pptx) |
| 07 | [Automations](07-automations.pptx) |

Each deck follows the same structure:

- A title slide and an "In this chapter" overview.
- A divider slide at the start of each section.
- Concept, exercise, and "Your turn" slides that use screenshots and illustrations from the chapter.
- A closing slide with key takeaways and links back to the chapter on GitHub.

Every slide has speaker notes. The slides use Arial and Courier New, so they display the same in PowerPoint, Keynote, and Google Slides.

If a chapter changes, update its deck so the steps and screenshots continue to match the course.
